Monte Carlo Simulation

Project Type: Computational Experiment

An experimental study using Monte Carlo simulation to investigate probabilistic systems and understand how repeated random sampling can be used to approximate mathematical quantities.

Objective

To explore how computational simulation can be used to study probability-based problems and compare simulated results with theoretical expectations.

Experimental Approach

  • Define the mathematical problem
  • Generate random samples
  • Run repeated simulations
  • Analyse simulated results
  • Compare simulation with theoretical results

Tools & Technologies

  • Python
  • NumPy
  • Matplotlib
  • Probability & Statistics
  • Monte Carlo Methods
